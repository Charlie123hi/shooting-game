# Shooting Game

A kour.io-style browser-based shooting game! Control your character, shoot enemies, and survive increasingly difficult waves.

## 🎮 How to Play

- **Move**: Use Arrow Keys or WASD
- **Shoot**: Click on the screen to shoot towards your cursor
- **Survive**: Eliminate all enemies to advance to the next wave
- **Health**: Avoid enemies - collisions damage you
- **Score**: Earn points by defeating enemies

## 🎯 Features

- **Wave System**: Enemies get faster and more numerous with each wave
- **Dynamic Difficulty**: The game gets progressively harder
- **Real-time Score & Health Tracking**: Monitor your progress
- **Smooth Controls**: Responsive player movement and shooting
- **Enemy AI**: Enemies chase the player intelligently

## 🚀 Getting Started

1. Open `index.html` in your web browser
2. Start playing immediately - no installation needed!
3. Try to survive as many waves as possible

## 📊 Game Mechanics

- Each enemy defeated: **10 points**
- Collision damage: **0.5 HP per frame** in contact with an enemy
- Wave progression: Automatically advances when all enemies are defeated
- Difficulty scaling: More enemies and faster speeds each wave

## 🛠️ Technologies

- HTML5 Canvas for rendering
- Vanilla JavaScript for game logic
- CSS3 for styling
